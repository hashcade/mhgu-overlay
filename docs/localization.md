# Localization sources

The language picker displays native names: English, 简体中文, 繁體中文,
日本語, and 한국어. Automatic detection remains available.

## Game names

- English and Japanese monster and food-skill names follow
  [Kiranico](https://mhxx.kiranico.com/).
- Traditional Chinese starts from the existing Chinese catalog, with regional
  terminology reviewed separately. This is not a new game-text extraction.
- Korean monster names follow the community's
  [monster list](https://namu.moe/w/몬스터%20헌터%20시리즈/몬스터%20목록)
  and [deviant list](https://seore.org/w/특수개체).
- Chinese and Korean food-skill names use Monster Hunter World Chronicles
  ([Japanese](https://mhw.poedb.tw/jpn/food_skills),
  [Traditional Chinese](https://mhw.poedb.tw/cht/food_skills),
  [Korean](https://mhw.poedb.tw/kor/food_skills)) only when the Japanese
  skill name exactly matches, after Unicode width normalization.

MHGU was not officially localized into Korean. Korean community names and
project translations must not be described as official MHGU translations.
Menu actions and status messages are project UI translations.
